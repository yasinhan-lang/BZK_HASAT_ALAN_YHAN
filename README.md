# BozokluHAN ALAN ÖLÇER (Bzk.Hasat)

Yürüyerek ya da biçerdöverle dolaşılan alanı **internetsiz**, telefonun GNSS (GPS) alıcısıyla doğru hesaplayan Android uygulaması.

- **İz (kenar turu):** Biçerdöverin ilk kenar turu kaydedilir, başlangıca dönülen yer bulunur, kapanma hatası kenarlara dağıtılır.
- **Köşe noktaları:** Her köşede birkaç saniyelik ortalama konum alınır.
- **Tabla payı:** Makine izi tabla genişliğinin yarısı kadar dışa ötelenir (tarlanın gerçek sınırı).
- Alan: yerel Transversal Merkatör (GRS80, k0=1) + Gauss alan formülü. m², dönüm, hektar; tahmini hata payı.
- Kroki, KML (Google Earth), TXT rapor, paylaşılabilir resim. Kayıtlar: `İndirilenler/BozokluHAN Alan Olcer`

APK: **Releases** bölümünden `BozokluHAN_Hasat_Alan.apk` indirilir.
